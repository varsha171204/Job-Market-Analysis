🚀 Tech Job Market Intelligence Dashboard

📌 Project Overview

This project analyzes tech job salary trends and builds a machine learning model to predict salaries. It also includes an interactive Power BI dashboard for visualization.

 🛠 Tools & Technologies

* Python (Pandas, Matplotlib)
* Machine Learning (Random Forest)
* Power BI
* SQL (basic usage)

 📊 Features

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Data Visualization
* Salary Prediction Model
* Interactive Dashboard

 📈 Key Insights

* Senior roles earn higher salaries
* Data Engineer & Data Scientist roles are in high demand
* Remote jobs offer competitive salaries



🤖 Model Performance

* Algorithm: Random Forest Regressor
* R² Score: ~0.33

 📂 Dataset

* Source: Kaggle (Data Science Salaries Dataset)
